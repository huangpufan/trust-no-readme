## Executive Verdict

Across all 146 repository files, 12,098 combined Git commits (`browser-use` + `browser-harness`), unpacked PyPI wheels, and 21 network-isolated sandbox captures, `browser-use` presents a sharp contrast: **its core engineering hygiene is strong** (cold-start `ANONYMIZED_TELEMETRY=false` is genuinely silent on the core library, zero foreign credential directory reads, 40-char GitHub Action SHAs, PyPI OIDC Trusted Publishing, `GHSA-x39x-9qw5-ghrf` properly patched).

Yet precisely because the team clearly knows how to build clean privacy and security controls (even masking password inputs in its own local session recorder), **five documented-vs-actual telemetry behaviors stand out as sustained product choices rather than isolated typos**:

1. **141 days of default raw script, stdout & plaintext password uploads (F1):** Hard-pinned `browser-harness==0.1.13` bypasses its own `FORBIDDEN_KEYS` scrubber; co-founder `MagMueller` closed fix PR `#733` unmerged 4h 27m before shipping `0.1.13`; a client-bookkeeping user (`#1053`) only discovered the uploads via an accidental Windows popup bug (`#6474`); `browser-use 1.0.8` and `HEAD` still pin `0.1.13`.
2. **Nov 9 three-hour disclosure wipe & payload expansion (F2):** Deleted `TELEMETRY.md`, re-enabled default `agent_event` uploads of internal hostnames, full URL paths, 500-char results, 2,100-char AI judge text, 50 custom tool names, and a 7-day disk spool 2h 54m later, then deleted the entire `README.md` Telemetry section 46 seconds later, leaving `1.0.0`–`1.0.5` with zero README telemetry disclosure for 6 days.
3. **Prompting 8 coding agents to bypass user telemetry opt-out, then doubling down 6 days later (F3):** Bundled `SKILL.md` directs Claude Code, Codex, Cursor, etc. to send feedback without asking; `cli.py` hard-codes `consent=True` (confirmed 994-byte POST with every switch off); 6 days after community pushback (`#6467`), `browser-harness#1068` removed even the hidden `BU_MODEL_CODE` escape hatch and noted under Risk: *"A model can call feedback without the user asking."*
4. **Silent person-profile tracking on `--help` and `--version` with hidden notices (F4):** Even running `browser-use --help` writes persistent `device_id`, sends `$process_person_profile: true`, and probes 12 coding-agent env vars while suppressing stderr notices and omitting `telemetry` from `--help`.
5. **Opt-out edge traps & aggressive workstation defaults (F5, F6):** Mid-process opt-out leaks queued events in `_at_exit()`, long-lived services permanently cache `telemetry.json`, cross-package env parsing diverges, `Agent()`/`MCP` execute unsandboxed host Python with undocumented permanent `$TMPDIR/browser_exec_*.txt` spill files, `HEAD` PR `#6526` auto-switches into personal Chrome / exposes `use_my_chrome()`, and default cloud browsers print unauthenticated `live_view` control URLs to `stderr`.

### F1: 141-day unredacted script, stdout & password uploads via hard-pinned `browser-harness==0.1.13` (PR `#733` closed unmerged; `#1053` GDPR demand)

**Rating:** `H4 / R3` · **Evidence:** `E3+D` · **Default:** Yes (`pip install`/`uv add` `.venv` CLI) · **Disclosure:** `public` · **Claim:** C1

- **The promise:** [`README.md:183`](https://github.com/browser-use/browser-use/blob/94784c1f7ecb6b0a5f565b7f9fba59e395b7e048/README.md#L183) promises telemetry sends anonymized stats and *"Never the task text, typed text, code or secrets."*
- **What the code actually does:** [`pyproject.toml:19`](https://github.com/browser-use/browser-use/blob/94784c1f7ecb6b0a5f565b7f9fba59e395b7e048/pyproject.toml#L19) (and PyPI `1.0.8` `METADATA`) hard-pins `"browser-harness==0.1.13"`, placing `browser-harness` on `.venv/bin/PATH` for `pip install` and `uv add` users. In `bh0113:src/browser_harness/telemetry.py:247-294`, `capture_cli_event()` bypasses the same file's 18-key `FORBIDDEN_KEYS` / `_safe_properties()` scrubber, sets `"$process_person_profile": True`, and spawns a detached subprocess posting to `eu.i.posthog.com`:
  - Up to **20,000 chars** of raw stdin Python script (`task`)
  - Up to **20,000 chars** of raw stdout (`output`)
  - Up to **500** traced helper calls with raw `args` (`steps`, e.g., `fill_input('#password', '<plaintext>')`, tokenized URLs)
  - Raw `error_message`, raw `cdp_url` hostname (`bh0113:src/browser_harness/telemetry.py:275-289`; [`browser_use/telemetry/stats.py:378-379`](https://github.com/browser-use/browser-use/blob/94784c1f7ecb6b0a5f565b7f9fba59e395b7e048/browser_use/telemetry/stats.py#L378-L379) notes a cloud browser hostname is itself a control capability), and 12 coding-agent environment probes.
  - Notably, the same package's local session recorder explicitly masks password inputs (`"•" * len(text)`), demonstrating awareness that typed passwords are sensitive while leaving the PostHog payload unredacted.

**Relevant source ([`bh0113:src/browser_harness/telemetry.py:264-292`](https://github.com/browser-use/browser-harness/blob/c24e5072ee66f8499bacd663f4f4bcb089bc4492/src/browser_harness/telemetry.py#L264-L292)):**
