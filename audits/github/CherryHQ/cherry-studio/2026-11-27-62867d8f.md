## Executive Verdict

Across all 14,056 repository files, 10,844 Git commits, the statically unpacked official `v2.2.3` Windows installer (`app.asar`), and isolated `bwrap --unshare-all` HTTPS captures, Cherry Studio shows solid controls in several areas (Sentry main-process PII is disabled and consent-gated, disabling `app.dist.auto_update.enabled` stops scheduled update checks, external-file deletion explicitly notifies users that originals are retained, and protocol-link MCP installs require separate trust confirmation).

However, four public code-vs-policy mismatches (plus one privately disclosed Windows updater signature issue) are directly verified in both shipped `v2.2.3` and `main` (`62867d8f`):

1. **CN-only raw `accountId` & US PostHog person profiles vs. "strictly anonymous / no profiling" copy (F1):** While Global builds send an anonymous UUID with `$process_person_profile: false`, CN builds (`edition === 'cn'`) embed raw `status.accountId` into `distinctId` and pass `processPersonProfile: true` to `https://us.i.posthog.com`, activated through a pre-checked onboarding consent box. Shipped `v2.2.3` still carries the `2026-08-20` privacy policy promising strict anonymity; unreleased PR `#25454` (`2026-11-26`) updated only the bundled HTML while leaving website policy and Settings UI copy ("匿名发送错误报告和数据统计") unchanged.
2. **431-day zero-click `plantuml` diagram transmission contradicting "never transmit chat data" (F2):** Any `plantuml` code block in chat auto-selects remote preview without user click and transmits the full compressed diagram source to hardcoded `https://www.plantuml.com/plantuml` (149 bytes recovered bit-for-bit in `bwrap` sandbox capture).
3. **Post-opt-out persistent `Client-Id` & undisclosed third-party IP geolocation (F3):** Disabling Privacy Settings data collection leaves `AppUpdaterService` sending persistent `Client-Id` (`app.user.id`) unless auto-update is also disabled, and packaged startup unconditionally queries undisclosed `api.ipinfo.io` (hardcoded token) and fallback `api.internetdata.io`.
4. **Manual MCP import grants `isTrusted: true` and connects on generic Confirm (F4):** Clicking generic "确认" during manual JSON/MCPB/DXT import immediately sets `isTrusted: true`, enables the server, and invokes `mcp.server.refresh_tools` without disclosing trust consequences.

- **The promise:** [`docs/website/content/about/privacypolicy.md:48`](https://github.com/CherryHQ/cherry-studio/blob/62867d8f0047919e37a1cd05315057d5cfcec09e/docs/website/content/about/privacypolicy.md#L48) (present since `2025-09-22`, [`cc650b58`](https://github.com/CherryHQ/cherry-studio/commit/cc650b58d3)) explicitly promises never to collect, store, or transmit chat data.

[`src/renderer/components/Preview/PlantUmlPreview.tsx:14,70-92`](https://github.com/CherryHQ/cherry-studio/blob/62867d8f0047919e37a1cd05315057d5cfcec09e/src/renderer/components/Preview/PlantUmlPreview.tsx#L70-L92) compresses the full diagram text via `pako.deflateRaw`, embeds it into hardcoded `https://www.plantuml.com/plantuml`, and calls `fetch(url)` automatically with no confirmation dialog, opt-out toggle, or custom server setting.

**Relevant source ([`src/renderer/components/Preview/PlantUmlPreview.tsx:70-92`](https://github.com/CherryHQ/cherry-studio/blob/62867d8f0047919e37a1cd05315057d5cfcec09e/src/renderer/components/Preview/PlantUmlPreview.tsx#L70-L92)):**

```ts
function encodeDiagram(diagram: string): string {
  const utf8text = new TextEncoder().encode(diagram)
  const compressed = pako.deflateRaw(utf8text)
  return encode64(compressed)
}

function getPlantUMLImageUrl(format: 'png' | 'svg', diagram: string, isDark?: boolean) {
  const encodedDiagram = encodeDiagram(diagram)
  if (isDark) {
    return `${PlantUMLServer}/d${format}/${encodedDiagram}`
  }
  return `${PlantUMLServer}/${format}/${encodedDiagram}`
}
```

- **Verification & exact scope:**
  - **Observed:** Confirmed verbatim inside shipped `v2.2.3` `app.asar` (`out/renderer/assets/PlantUmlPreview-RsIXcvSS.js`). Running that shipped bundle inside `bwrap --unshare-all` captured `GET https://www.plantuml.com/plantuml/svg/<encoded>`; independent reverse-decoding recovered all **149 bytes** of the decoy architecture diagram bit-for-bit.
  - **What is NOT affected:** Only messages containing `plantuml` code blocks trigger this path; React auto-preview lifecycle is verified statically (`E3`), while encoder serialization and wire egress are dynamically verified (`D`).
- **Timeline:**
  - `2025-02-18` ([`d0ee7647`](https://github.com/CherryHQ/cherry-studio/commit/d0ee764732)): Online PlantUML rendering introduced.

- **Mitigation:** Avoid generating or rendering `plantuml` code blocks for confidential diagrams until Cherry Studio defaults to source view or supports local rendering.
